Phoenix-TSA

PROJECT SUMMARY

The Phoenix Cohort project is a React web application focused on planetary science, designed to provide information about the planets in our solar system. It presents key facts and descriptions about each planet in an organized and easy-to-understand format.

The project allows users to learn about different planets, their characteristics, and their place in the solar system. It was developed as a group effort to compile and display educational space-related content in a simple and accessible way.

How to Run Locally

```bash
# Clone the repository
git clone https://github.com/Father-rbb/Phoenix-TSA.git

# Navigate into the project folder
cd Phoenix-TSA

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open your browser at `http://localhost:5173`
